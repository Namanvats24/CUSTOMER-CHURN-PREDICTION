# Customer Churn Prediction

A machine learning web app that predicts whether a bank customer is likely to churn, built with an Artificial Neural Network (ANN) and deployed with Streamlit.

🔗 **Live App:** https://your-app-link.streamlit.app

## Features
- Predicts churn probability based on customer demographics and account details
- Built with TensorFlow/Keras ANN model
- Preprocessing with one-hot encoding, label encoding, and feature scaling
- Interactive Streamlit UI

## Tech Stack
- Python, TensorFlow/Keras, Scikit-learn, Pandas, NumPy
- Streamlit (deployment)

## How to run locally
\`\`\`bash
git clone https://github.com/Namanvats24/CUSTOMER-CHURN-PREDICTION.git
cd CUSTOMER-CHURN-PREDICTION
pip install -r requirements.txt
streamlit run app.py
\`\`\`
